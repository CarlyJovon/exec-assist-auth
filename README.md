# The Executive Assist - Full Stack Task Management App
**The Executive Assist** is a full-stack application featuring secure user authentication, session management, and a personalized task scheduling dashboard. Users can create accounts, manage their sessions, and organize private schedules and notes in a secure, user-specific workspace.

# Features 
- **User Authentication:** Secure registration, login, and logout using Passport.js
- **Session Management:** Maintain authenticated user sessions
- **Private Dashboard:** Display user profile and account information
- **Task Management:** Create and delete scheduled tasks and notes
- **User Data Protection:** Restrict database access so users can only manage their own tasks
- **Dynamic Deletion:** Remove tasks asynchronously without refreshing the page

# Tech Stack
- JavaScript
- HTML5 & CSS3
- Node.js
- Express.js
- Passport.js
- MongoDB & MongoDB Atlas
- EJS
- Bootstrap 3

# Installation 
1. Clone the repository: 
```bash
git clone https://github.com/CarlyJovon/exec-assist-auth.git
```
2. Navigate into the project folder:
```bash
cd exec-assist-auth
```
3. Install dependencies:
```bash
npm install
```
4. Create a `.env` file with the required environment variables, including your MongoDB connection string and session configuration.
5. Start the application:
```bash
npm start
```
6. Open http://localhost:3000 in your browser.
